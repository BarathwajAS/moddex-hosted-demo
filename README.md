# ModDex

Bike and car modification visualiser for Detailing Mafia, Chennai.

Upload a customer's vehicle photo, pick modifications, and preview the result
before any work is done.

Access is protected by a staff PIN. Set a Space secret named `MODDEX_PIN`.
